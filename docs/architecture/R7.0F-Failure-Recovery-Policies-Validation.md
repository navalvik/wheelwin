## Architecture

```text
Subsystem failure
  → FailurePolicyManager.decide()
      → FailureClassifier (category)
      → CircuitBreaker check (external deps only)
      → FailureDecisionEngine (decision)
      → FailureEscalation (persistent streaks)
      → BackoffStrategy (RETRY_LATER delay)
  → Subsystem executes decision
  → scheduleRetry() via RetryScheduler (async, unref'd timers)
```

Gameplay never uses circuit breakers or policy retries. RecoveryEngine unchanged.

---

## Categories → Decisions

| Category | Typical decision |
|----------|------------------|
| RECOVERABLE | RETRY_LATER |
| TRANSIENT | RETRY_NOW (non-gameplay) / IGNORE (gameplay) |
| RATE_LIMITED | RETRY_LATER (backoff) |
| NON_RECOVERABLE | FAIL |
| FATAL | SHUTDOWN |
