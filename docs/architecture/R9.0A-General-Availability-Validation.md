## Architecture

```text
GeneralAvailabilityManager (lifecycle owner)
  ├── ReleaseOrchestrator
  ├── RolloutManager (single | staged)
  ├── ProductionVerificationManager (read-only)
  ├── RollbackCoordinator (CRITICAL only)
  ├── ProductionStateManager
  ├── ReleaseAnnouncementManager (metadata only)
  ├── ProductionEvidenceRegistry (immutable + hash)
  ├── ProductionMetricsCollector
  └── ProductionReportBuilder
```

Lifecycle:

```text
READY_FOR_RELEASE → RELEASE_STARTED → ROLLOUT
  → PRODUCTION_VERIFICATION → GA_ACTIVE
  → POST_LAUNCH_MONITORING → STABLE_RELEASE
```
