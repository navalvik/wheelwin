# R7.67A — Testnet GameEscrow Default

**Status:** Active for Testnet  
**Scope:** Escrow deploy/settle mode defaults only (no Page6 gate, TonConnect, or payment UX changes)

## Summary

On **Testnet**, WheelWin defaults to real **GameEscrow** (`GAME_ESCROW_MODE=game`) for contract deployment and settlement.

**Mainnet** configuration is unchanged: default remains legacy **WalletContractV4** (`GAME_ESCROW_MODE=v4`). Legacy code is retained for rollback.

## Testnet GameEscrow flow

1. Room reaches payments-complete; `GameContractManager` requests deploy.
2. `TonGameContractAdapter` builds **GameEscrow** StateInit (`code` + `data` from compiled artifact).
3. Deployer wallet broadcasts StateInit (requires `TON_DEPLOY_MODE=live` + mnemonic).
4. After deploy, oracle path sends **INIT_GAME** (oracle, owner, contractIdHash, snapshotHash).
5. On winner determination, settlement adapter sends **SETTLE** (snapshotHash, winner, amounts).
6. Status stays `SETTLEMENT_PENDING_CONFIRMATION` until winner/owner payout proofs are verified.
7. On verified payouts → `SETTLEMENT_COMPLETED`.

Startup logs the active mode:

```text
GameEscrowMode=game (network=testnet)
```

or

```text
GameEscrowMode=v4 (network=testnet)
```

## Environment

| Variable | Testnet default | Mainnet default | Notes |
|----------|-----------------|-----------------|-------|
| `TON_NETWORK` | `testnet` | `mainnet` | Required |
| `GAME_ESCROW_MODE` | **`game`** (when unset) | **`v4`** (when unset) | Only `v4` or `game` allowed |
| `TON_DEPLOY_MODE` | `stub` / `live` | unchanged | `live` needed for real broadcasts |
| `TON_DEPLOYER_MNEMONIC` | required for live | unchanged | Deployer / oracle signer |

Ambiguous values (empty, typos such as `legacy`, `GameEscrow`) cause **startup failure**.

## Rollback procedure (Testnet → V4)

1. Set explicit override:

   ```bash
   GAME_ESCROW_MODE=v4
   ```

2. Restart the server. Confirm startup line:

   ```text
   GameEscrowMode=v4 (network=testnet)
   ```

3. New games use legacy WalletContractV4 StateInit and the previous settlement path.
4. Do **not** mix modes mid-game for an already-deployed escrow address; finish or abandon in-flight games before flipping the flag if possible.
5. To return to GameEscrow: set `GAME_ESCROW_MODE=game` (or remove the variable on testnet) and restart.

Mainnet must not be switched to `game` under this release; keep `v4` (default) until a dedicated mainnet GameEscrow rollout.

## Wallet requirements

| Role | Requirement |
|------|-------------|
| **Deployer / oracle** | Wallet funded on **testnet**; mnemonic in `TON_DEPLOYER_MNEMONIC`; enough TON for StateInit + INIT_GAME + SETTLE gas |
| **Owner** | Configured owner wallet (`OWNER_WALLET` / owner config); receives organizer fee on SETTLE |
| **Players** | TonConnect wallets on testnet; pay entry to the **GameEscrow** address (unchanged payment UX) |
| **Artifact** | Compiled `server/payment/ton/artifacts/GameEscrow.code.boc` present (from `contracts` Blueprint build) |
