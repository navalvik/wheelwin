## 4. Event / observability mapping

The validation spec uses some labels that differ from emitted domain events. Actual production mapping:

| Spec label | Actual emission |
|------------|-----------------|
| `GAME_CONTRACT_DEPLOY_STARTED` | `decisionTrace` stage **`BEGIN_DEPLOY`** + domain **`CONTRACT_DEPLOYING`** |
| `DEPLOYER_BALANCE_PREFLIGHT` | Logger **`GAME_CONTRACT_DEPLOY_PREFLIGHT_STARTED`** + debug stage |
| Preflight pass | Logger **`GAME_CONTRACT_DEPLOY_PREFLIGHT_PASSED`** + debug stage |
| Preflight fail | Logger **`GAME_CONTRACT_DEPLOY_PREFLIGHT_FAILED`** + reason **`INSUFFICIENT_DEPLOYER_BALANCE`** |
| Deploy success | **`GAME_CONTRACT_DEPLOYED`** + **`CONTRACT_DEPLOYED`** |
| Ready for stakes | **`GAME_CONTRACT_READY_FOR_PAYMENTS`** |
| Payment request | **`PAYMENT_REQUEST`** (via PaymentSessionManager) |
| Payment complete | **`PAYMENT_SESSION_COMPLETED`** / **`PAYMENT_COMPLETED`** |

No mnemonic, privateKey, seed, or secret appears in preflight logs or API responses (verified in R17.8M.1/M.2 tests).
