## Architecture

```text
LaunchReadinessManager (lifecycle owner)
  ├── OpenBetaReadinessEvaluator
  ├── ProductionLaunchEvaluator
  ├── LaunchGateEvaluator
  ├── LaunchDecisionManager
  ├── LaunchEvidenceRegistry (immutable + hash)
  ├── LaunchChecklist
  ├── LaunchMetricsCollector
  └── LaunchReportBuilder
```

Lifecycle (manager-only):

```text
NOT_EVALUATED → CLOSED_BETA_REVIEW → OPEN_BETA_APPROVED
  → OPEN_BETA_RUNNING → GA_REVIEW → GA_APPROVED → PRODUCTION_READY
```

Decisions (automatic):

```text
NOT_READY | BLOCKED | READY_FOR_OPEN_BETA | READY_FOR_GA | READY_FOR_PRODUCTION
```

Only **CRITICAL** blockers prevent `READY_FOR_PRODUCTION`.
