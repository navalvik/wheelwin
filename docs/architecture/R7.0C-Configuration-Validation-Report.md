## Configuration flow

```text
Process Environment
  → validateEnvironment (schema)
  → validateSecrets (presence / strength)
  → loadEnvironment (existing loaders)
  → loadOwnerConfiguration (owner.json)
  → loadDeveloperConfiguration
  → validateConfiguration (cross-cutting)
  → Immutable RuntimeConfiguration
  → ApplicationLifecycleManager → RUNNING
```

Invalid configuration never reaches `RUNNING`. Process exits non-zero via `ConfigurationError`.

---

## Secret policy

Treated as secrets (never logged / REST / console / metrics / stack-friendly dumps):

- `DEVELOPER_AUTH_PASSWORD`
- `DEVELOPER_AUTH_SECRET`
- `TON_DEPLOYER_MNEMONIC`
- `TON_API_KEY`
- `ownerWallet`

Safe summaries expose only booleans such as `apiKeyConfigured` / `mnemonicConfigured` / `owner.loaded`.

Production & staging reject:

- Disabled developer auth
- Missing / short / example developer secrets
- `DEBUG_SIMULATION_LOOP` / startup demonstrations
- `TON_DEPLOY_MODE=live` without mnemonic
