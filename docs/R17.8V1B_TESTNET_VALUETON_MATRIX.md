## How to run

### Dry-run (no chain)

```bash
node server/scripts/run-testnet-valueton-sweep.js --dry-run
```

### Live testnet sweep

```bash
# server/.env must provide TON_DEPLOYER_MNEMONIC and testnet endpoint/key
set TON_NETWORK=testnet
set TON_DEPLOY_MODE=live
set RUN_TESTNET_VALUETON_SWEEP=true
set TEST_VALUETON_OVERRIDE=true
set TEST_VALUETON_SWEEP_VALUES=0.05,0.04,0.03,0.025,0.02,0.015,0.01
set TEST_VALUETON_SCENARIOS=A,B,C
set TEST_VALUETON_STAKE_TON=0.05
node server/scripts/run-testnet-valueton-sweep.js
```

Optional per-message overrides (used by adapter when override flag is true):

```text
TEST_VALUETON_DEPLOY
TEST_VALUETON_INIT
TEST_VALUETON_OPEN
TEST_VALUETON_CANCEL
TEST_VALUETON_SETTLE
```

Live runs write JSON to:

```text
server/tests/testnet/artifacts/valueton-sweep-last-run.json
```

Then paste outcomes into the tables below.
