## Architecture

```text
LoggerService (facade) → LoggingManager → async queue → transports
                                      ↘ recent ring buffer → Console gateway
Application + Audit channels
```

- **Async enqueue** (`setImmediate`) — file I/O never runs inline on the gameplay tick.
- **LoggerService** remains the call-site API used across the server (no mass rewrite).
- **LoggingManager** is the sole structured logging engine.

## Security

`LogSanitizer` redacts secret keys and inline `password=` / `token=` patterns. Safe health/console status exposes only `application.log` / `audit.log` **names**, never absolute paths.
