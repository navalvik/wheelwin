# FREQUENTLY ASKED QUESTIONS (FAQ)

## What is WheelWin?

WheelWin is a multiplayer peer-versus-peer game where three real players compete against each other.

The server never participates as a player. It only manages the game and verifies the rules.

---

## How many players can join a game?

Every game always has exactly **3 players**.

The game cannot start with fewer or more players.

---

## How many sectors can I buy?

Each player may purchase:

* **1 sector**
* **2 sectors**

No player can purchase more than two sectors.

---

## Do all sectors have the same chance to win?

Yes.

Every purchased sector has exactly the same probability.

There are:

* no bonus sectors,
* no hidden multipliers,
* no weighted probabilities,
* no jackpot sectors.

---

## How much does it cost to play?

Every room uses one of two base stakes:

* **1 GRM**
* **10 GRM**

The room creator selects the stake before the game begins.

---

## How much does the second sector cost?

The second sector costs **1.5×** the selected base stake.

Example:

Base stake:

**1 GRM**

Second sector:

**1.5 GRM**

---

## How is the winner selected?

The winner is determined by the final position of the wheel.

The game is controlled by the server using deterministic physics.

No player can influence the result after the game starts.

---

## How is the prize distributed?

After all blockchain confirmations:

* **95%** goes to the winning player.
* **5%** goes to the organizer.

The payout is performed automatically by the smart contract.

---

## Which wallet is supported?

WheelWin supports only:

**Telegram Wallet**

No other cryptocurrency wallets are supported.

---

## Which blockchain is used?

WheelWin uses the **TON blockchain**.

All entry payments and prize settlements are verified on-chain.

---

## Can I cancel my payment?

Once a blockchain transaction is confirmed, it cannot be cancelled.

Please verify all information before confirming payment.

---

## What happens if I lose my internet connection?

If you disconnect during the game:

* the game continues under server control;
* you may reconnect if the session is still active;
* if your purchased sector wins, the prize is still transferred to your wallet after settlement.

---

## Can someone cheat?

WheelWin is designed to prevent manipulation.

The game uses:

* Server Authoritative architecture
* Immutable game configuration
* Blockchain payment verification
* Secure audit logging

---

## Does the server know the result before the wheel stops?

No.

The server controls the simulation but does not manually choose the winner.

The winner is determined by the authoritative game simulation.

---

## Can the organizer change the result?

No.

The organizer cannot modify:

* player sectors,
* wheel configuration,
* game physics,
* winner selection,
* prize distribution.

---

## Why do I have to wait for other players?

The game begins only after:

* all three players have joined,
* all player information is verified,
* all wallets are connected,
* every payment is confirmed on the blockchain.

This ensures that every game starts under the same conditions.

---

## Is WheelWin a casino?

No.

WheelWin is a peer-versus-peer multiplayer game.

Players compete only against each other.

The server never acts as a player and does not compete against users.
