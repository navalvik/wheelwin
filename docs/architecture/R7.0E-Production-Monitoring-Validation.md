## Architecture

```text
Providers (managers/getters/MetricsService)
  → Collectors (async intervals via MetricsScheduler)
  → MetricsRegistry
  → MetricsSnapshot
  → Health / Console projections / Prometheus text
```

Collection failures are swallowed per collector — gameplay never interrupted.

## Prometheus

- Mounted on main HTTP app at `PROMETHEUS_PATH` (default `/metrics`) when enabled.
- Optional sidecar when `PROMETHEUS_PORT` differs from server `PORT`.
- Read-only OpenMetrics/Prometheus text; no secrets.
