# R17.9T.8 — Metrics Console Row Contract Fix

Date: 2026-08-24

Task: narrowly scoped frontend data-shape bug fix for the production `/debug` crash introduced by the R17.9T.8 console gauge visibility completion (`a39fe42`). Correction of the immediately previous R17.9T.8 console visibility implementation only.

## 1. Production Symptom

Production `/debug` black-screened with:

`Uncaught TypeError: Cannot read properties of undefined (reading 'name')`

## 2. Confirmed Root Cause

`client/src/console/panels/shared/DataTable.jsx` renders cells via `row.data[column.key]`. The established row contract is `{ id, data: { name, value } }`. The new `buildRoomPoolRows()` returned flat rows `{ id, name, value }`, so `row.data` was `undefined` → crash on `row.data["name"]`.

## 3. Fix (minimal, in metricsRoomPool.js only)

Rows now return `{ id, data: { name, value } }`, matching the working timing/counter row shapes. Gauge names, calculations, formatting rules, null handling, projection structure, collector, backend, and DataTable itself are unchanged.
