## Architecture

```text
ClosedBetaManager (lifecycle owner)
  ├── BetaParticipantRegistry
  ├── BetaTelemetryManager  ← MetricsService / Monitoring (read-only)
  ├── BetaFeedbackManager
  ├── BetaIncidentManager
  ├── BetaCrashCollector (redacted stacks)
  ├── BetaMetricsCollector
  ├── BetaReadinessEvaluator
  └── BetaReportBuilder → docs/release/R8.0D-Closed-Beta-Report.md
```

Lifecycle (manager-only transitions):

```text
NOT_STARTED → INVITATION → ACTIVE → MONITORING
  → READY_FOR_REVIEW → COMPLETED → OPEN_BETA_READY
```

Readiness (automatic):

```text
NOT_READY → NEEDS_ATTENTION → READY_FOR_OPEN_BETA
```
