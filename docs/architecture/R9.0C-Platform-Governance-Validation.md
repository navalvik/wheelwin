## Architecture

```text
GovernanceManager (lifecycle owner)
  ├── OperationalAuditManager
  ├── ComplianceManager
  ├── GovernancePolicyManager
  ├── ChangeGovernanceManager
  ├── RiskAssessmentManager
  ├── EvidenceArchiveManager
  ├── AuditTrailManager
  ├── PlatformReviewManager
  ├── GovernanceMetricsCollector
  └── GovernanceReportBuilder
```

Governance lifecycle:

```text
PLATFORM_ACTIVE → AUDIT_WINDOW → COMPLIANCE_VALIDATION
  → RISK_REVIEW → PLATFORM_REVIEW → GOVERNANCE_APPROVED
  → NEXT_AUDIT_CYCLE → (next cycle)
```

## Governance recommendations

1. Run `npm run governance:report` on a fixed cadence aligned with `AUDIT_INTERVAL_DAYS`.
2. Treat FAILED compliance items as remediation-tracked work outside runtime.
3. Retain evidence archives for at least `EVIDENCE_RETENTION_DAYS`.
4. Keep governance observational — never wire governance decisions into gameplay or payment mutation paths.
