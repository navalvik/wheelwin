# WheelWin Project Flow

## Screen Flow

```
Page1 Welcome
      │
      ▼
RoomLobby
(Create / Join Room)
      │
      ▼
Page2 Player Setup
      │
      ▼
Page3 Verify Players
      │
      ▼
Page4 Payment
      │
      ▼
Page5 Wheel Game
      │
      ▼
Page6 Result
```

---

## Description

### Page1

Project information.

Rules.

Documentation.

Useful links.

---

### RoomLobby

Player creates a room or joins an existing room.

The server generates Room ID.

All three players connect.

When the room is full the game starts.

---

### Page2

Every player enters:

- Language
- Nickname
- Age
- Number of occupied sectors (1 or 2)
- Investment (1 or 10 TON)
- Secret Code

---

### Page3

Verification of all players.

---

### Page4

TON payment confirmation.

---

### Page5

Wheel game.

---

### Page6

Winner announcement.

Prize distribution.
