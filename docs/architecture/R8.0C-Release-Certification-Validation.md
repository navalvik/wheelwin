## Certification model

```text
Release package (R8.0B)
  → ReleaseCertificationManager.certify()
      → Checklist checks (read-only)
      → Immutable evidence[]
      → Evidence hash
      → ReleaseCertificate.json
      → Release-Certification-Report.md
```

States: `NOT_CERTIFIED` → `RUNNING` → `PASSED` | `PASSED_WITH_WARNINGS` | `FAILED`

**Closed Beta may begin only when status is `PASSED` or `PASSED_WITH_WARNINGS`.**
